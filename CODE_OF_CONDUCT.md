# 🤝 Code of Conduct

## Commitment
The Chess Academy Management System project aims to provide a respectful space for people learning Java, chess administration workflows, and collaborative software development.

## Expected behavior
- Communicate respectfully and assume good intent.
- Critique code and ideas, not people.
- Explain technical concerns with evidence and practical alternatives.
- Respect different experience levels and communication styles.
- Keep discussions focused on the project.
- Protect private information; never publish credentials or personal records.
- Respect applicable licenses and acknowledge external contributions.

## Unacceptable behavior
Harassment, discrimination, threats, personal attacks, doxxing, deliberate disruption, spam, publishing secrets, and knowingly submitting malicious code are unacceptable.

## Scope
This policy applies in repository issues, pull requests, code reviews, discussions, and project-related communication spaces.

## Reporting
Report concerns privately to the repository owner using the contact mechanism on the GitHub profile. Do not publish sensitive details in a public issue. Include relevant URLs, approximate dates, and a concise factual description.

## Enforcement
The maintainer will review reports as promptly as practical, seek context, and choose a proportionate response. Actions may include a request to stop, content removal, temporary participation restrictions, or permanent exclusion. Retaliation against good-faith reporting is prohibited.

## Maintainer responsibilities
Apply this policy consistently, protect reporter confidentiality where possible, document material decisions, and avoid disclosing private reports.
