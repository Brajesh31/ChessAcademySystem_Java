# 🆘 Support

## Where to ask
- Bugs: Bug Report issue form.
- Feature proposals: Feature Request.
- Documentation errors: Documentation issue.
- Security issues: follow [SECURITY.md](SECURITY.md), not a public issue.
- Usage questions: include command, JDK version, OS, expected behavior, and actual output.

## Diagnostics
Include operating system, `java -version`, `javac -version`, compile/run command, working-directory context, record-file presence, and minimal synthetic input. Remove secrets and personal data.

## First troubleshooting steps
1. Run commands from repository root.
2. Compile with `javac chessAcademy.java`.
3. Run with `java chessAcademy`.
4. Check working-directory read/write permissions.
5. Confirm records follow the documented comma-separated layout.
6. Read [troubleshooting.md](docs/troubleshooting.md).

This is a small project without a formal support team or SLA. Responses are best effort.
