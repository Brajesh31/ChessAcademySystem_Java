# 🧭 Project background and objectives

The repository contains a compact Java program named `chessAcademy`. It implements a learning-oriented flow: compare input against an in-source credential table, display a role-specific menu, collect record fields, and append them to local files.

## Objectives implemented
1. Demonstrate a login loop.
2. Distinguish administrator and regular menus.
3. Add and list player information.
4. Search players by registration-number prefix.
5. Add and list tournament information.
6. Search tournaments by name prefix.
7. Provide help and logout confirmation.

## Future engineering objectives
- Improve input validation and error recovery.
- Separate domain logic from terminal interaction.
- Replace plaintext credentials with secure account handling.
- Define robust data parsing and malformed-record behavior.
- Add automated tests and backup/recovery procedures.

## Constraints
One Java source file; no declared build tool, test framework, dependency manifest, database, or service infrastructure.
