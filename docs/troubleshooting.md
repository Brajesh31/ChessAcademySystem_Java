# 🧯 Troubleshooting

| Symptom | Likely cause | Check |
|---|---|---|
| javac not found | JDK absent or PATH incomplete | Install JDK; check version |
| Main class not found | Wrong working directory/output location | Compile and run consistently |
| Data not visible | Different process working directory | Check current directory |
| Save error | Directory not writable or filesystem issue | Check permissions and storage |
| Read error | File missing or unreadable | Check path and permissions |
| DOB repeats | Input does not match DD/MM/YYYY shape | Enter expected two/two/four digits |
| Menu exits on text input | Unchecked nextInt path | Use numeric input; report defect |
| Search misses row | Prefix/case-sensitive matching | Check exact field and delimiter |

Never include passwords or real player information in public reports. Use synthetic examples.
